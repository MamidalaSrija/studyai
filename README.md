# StudyAI – AI Student Assistant

StudyAI is a student-focused web application designed to bring useful study tools into one simple platform.

## 🚀 Features

- 💡 **AI Doubt Solver**
  - Ask academic questions and receive simple explanations.

- 📝 **Notes Summarizer**
  - Convert lengthy study notes into short, easy-to-revise points.

- 🎯 **Quiz Generator**
  - Generate practice questions based on a selected topic.
  - Interactive answer checking.

- 📅 **Study Planner**
  - Create an organized study plan based on subject and available study hours.

## 🛠️ Technologies Used

- Vite
- JavaScript
- HTML5
- CSS3
- Node.js
- npm
